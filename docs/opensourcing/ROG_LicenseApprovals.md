The tables serve as guideline to what licenses are acceptable in the code base but do not represent Legal advice.

In every case refer to the specified license for obligations - regardless of license category all license obligations must be fulfilled.

Code / Text snippets from the Internet with no clear license CANNOT be used in any code/documentation.

If they have a license, ensure the license is approved and the license and copyright obligations are met.
